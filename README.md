# To-Do List

해야 할 일을 등록하고 우선순위와 마감 일시를 관리할 수 있는 반응형 To-Do 웹 애플리케이션입니다. 완료 상태와 진행률을 확인하고, 목록을 브라우저에 저장해 새로고침 후에도 이어서 사용할 수 있습니다.

## 주요 기능

- 할 일 추가, 완료/미완료 전환, 삭제
- 우선순위(낮음·보통·높음)와 선택형 마감 일시 지정
- 전체·진행 중·완료 필터 및 전체/완료 개수와 진행률 표시
- 공백 입력 및 200자 초과 입력 안내
- HTML 태그를 실행하지 않고 텍스트로 표시
- `localStorage` 저장 및 손상되거나 이전 형식인 데이터에 대한 기본값 처리
- 모바일 화면을 포함한 반응형 레이아웃
- 완료 시 꽃가루 효과와 삭제 확인 팝업

## 어떻게 만들었나요

먼저 [PRD.md](./PRD.md)에 사용자 기능, 데이터 구조, 예외 처리, 저장 방식과 확인 가능한 완료 기준을 정리했습니다. 그 요구사항을 기준으로 화면 구조는 `index.html`, 디자인은 `style.css`, 상태와 동작은 `script.js`에 나누어 구현했습니다.

현재 체크아웃된 `bootstrap` 브랜치에서는 Bootstrap 5를 CDN으로 불러옵니다. 구현을 다듬으면서 PRD에 마감 일시와 우선순위 요구사항을 반영했고, 완료 체크의 꽃가루 애니메이션과 삭제 확인 팝업도 추가했습니다. 자세한 실습 흐름은 [guide.md](./guide.md)를 참고하세요.

## Bootstrap vs Tailwind

Bootstrap은 준비된 컴포넌트와 레이아웃 클래스를 조합하는 방식이고, Tailwind CSS는 여백·색상·정렬 같은 작은 유틸리티 클래스를 HTML에 조합하는 방식입니다. 따라서 Bootstrap은 익숙한 입력 그룹이나 버튼을 빠르게 구성하기 좋고, Tailwind는 세부적인 모양과 간격을 마크업 가까이에서 조정하기 편합니다.

이 README를 작성하는 현재 저장소에는 `bootstrap` 브랜치의 구현이 체크아웃되어 있습니다. 여기서 확인할 수 있는 버튼 클래스는 `btn btn-primary px-4`처럼 Bootstrap 컴포넌트 기반입니다. Tailwind 버전의 실제 화면이나 코드는 이 브랜치에 포함되어 있지 않으므로, 두 버전의 직접 비교 결과를 사실처럼 단정하지 않습니다. 이 버전에서는 Bootstrap의 준비된 반응형 컴포넌트와 빠른 화면 구성을 선택했습니다.

## 실행 방법

Node.js 설치나 별도의 빌드 과정 없이 정적 파일로 실행할 수 있습니다. Bootstrap CSS를 CDN에서 불러오므로 인터넷 연결이 필요합니다.

저장소 루트에서 로컬 서버를 실행합니다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. 서버를 종료하려면 터미널에서 `Ctrl + C`를 누릅니다.

GitHub Pages 배포가 설정된 저장소에서는 다음 주소 형식을 사용합니다.

```text
https://<GitHub 사용자명>.github.io/26-w08-todo/
```

현재 이 브랜치에서 Pages 배포 여부는 확인하지 않았습니다. 배포하려면 저장소의 **Settings → Pages**에서 배포 브랜치와 루트 폴더를 지정하세요. 과정은 [guide.md](./guide.md)의 GitHub Pages 안내를 참고할 수 있습니다.

## 커스터마이징한 부분

- 마감 일시를 선택하고 우선순위(낮음·보통·높음)를 지정할 수 있도록 했습니다. 마감이 지난 미완료 항목에는 기한 초과 상태를 표시합니다.
- 완료 체크 시 색상 파티클을 보여주고, 사용자의 모션 감소 설정을 존중합니다.
- 삭제 전에 할 일 내용을 확인하는 앱 내 팝업을 표시합니다. 취소/삭제 버튼, 키보드 닫기, 닫은 후 포커스 복귀를 지원하며 아이콘은 독자적인 SVG로 제작했습니다.
- 입력 글자 수를 표시하고, localStorage에 이전 데이터 형식이 있으면 새 선택 필드의 기본값을 적용합니다.
- 긴 할 일 내용이 모바일에서 체크박스와 삭제 버튼을 밀어내지 않도록 줄바꿈과 반응형 레이아웃을 적용했습니다.
